# Alibaba Cloud (Qwen / Tongyi Qianwen)

## Overview
Alibaba Cloud's AI division develops the Qwen (Tongyi Qianwen) series of large language models. Major player in China's AI landscape with strong open-source presence.

## Key Models
- **Qwen 2.5**: Latest generation with multiple sizes (0.5B to 72B)
- **Qwen 2**: Previous generation
- **Qwen-VL**: Vision-language multimodal models
- **Qwen-Audio**: Audio understanding models
- **Qwen-Coder**: Specialized for code generation

## Products
- **Tongyi Qianwen**: Consumer AI assistant in China
- **Alibaba Cloud Model Studio**: Developer platform
- **Qwen on Hugging Face**: Open-weight models for community use
