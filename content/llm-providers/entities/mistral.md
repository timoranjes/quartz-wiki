# Mistral AI

## Overview
Mistral AI is a French AI company founded in 2023, developing open-weight and commercial large language models. Headquartered in Paris.

## Key Models
- **Mistral Large 2**: Flagship model for complex tasks
- **Mistral NeMo**: Joint development with NVIDIA for efficient inference
- **Mistral Small**: Cost-effective model for everyday tasks
- **Codestral**: Specialized for code generation
- **Mixtral 8x22B**: Mixture-of-experts architecture

## Products
- **Le Chat**: Consumer chat interface
- **Mistral API**: Developer platform
- **Enterprise solutions**: Business deployment options
