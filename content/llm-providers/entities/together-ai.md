# Together AI

## Overview
Together AI is an **open-weight model hosting and inference platform** — provides fast API access to hundreds of open-source models.

## Key Offerings
- **Model Hub**: 100+ open-weight models (Llama, Qwen, Mistral, DeepSeek, etc.)
- **Fast Inference**: Optimized serving stack for low latency
- **Fine-tuning**: Custom fine-tuning on open-weight models
- **RedPajama**: Open dataset initiative (1.2T+ tokens)

## Strengths
- **Speed**: Among the fastest inference providers for open models
- **Coverage**: Nearly every major open-weight model available
- **Developer experience**: OpenAI-compatible API, excellent docs
- **Research**: Contributes to open-source ecosystem (RedPajama)

## Pricing
| Category | Price Range |
|----------|------------|
| Small models (<10B) | $0.05–$0.10/1M input |
| Mid models (10-70B) | $0.20–$0.90/1M input |
| Large models (70B+) | $0.90–$3.50/1M input |

## Positioning
Not a model creator — an inference layer on top of others' models. Competes with OpenRouter, Groq, Anyscale.
