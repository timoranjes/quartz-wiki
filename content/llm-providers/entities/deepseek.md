# DeepSeek

## Overview
DeepSeek is a Chinese AI company founded by hedge fund High-Flyer, developing large language models with focus on efficiency and reasoning capabilities.

## Key Models
- **DeepSeek-V3**: Latest flagship model with Mixture-of-Experts architecture
- **DeepSeek-R1**: Reasoning-focused model with chain-of-thought
- **DeepSeek-V2**: Previous generation
- **DeepSeek-Coder**: Specialized for code generation

## Products
- **DeepSeek Chat**: Consumer interface
- **DeepSeek API**: Developer access
- **Open-weight releases**: Models available on Hugging Face
