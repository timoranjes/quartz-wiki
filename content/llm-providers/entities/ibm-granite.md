# IBM (Granite)

## Overview
IBM develops the **Granite** series of open-weight models, focused on enterprise and code generation use cases.

## Key Models (2026)

| Model | Params | Notes |
|-------|--------|-------|
| Granite 3.2 | 1B–8B | Latest generation |
| Granite Code | 3B–34B | Code-specialized |
| Granite Guardian | 3B | Safety/guardrail model |
| Granite Embeddings | — | Embedding model |

## Strengths
- **Enterprise focus**: Built for watsonx platform
- **Code generation**: Granite Code competitive with models 10× its size
- **Safety**: Granite Guardian for content filtering
- **Open-weight**: All models Apache 2.0

## Pricing
All models are free to download and self-host.

## Positioning
Enterprise-focused open-weight provider. Granite models are competitive on code benchmarks but less known for general language tasks.
