# Amazon (Nova)

## Overview
Amazon entered the LLM market with the **Nova** series, distributed through Amazon Bedrock. Competes with other cloud providers (Azure/OpenAI, Google/Vertex).

## Key Models (2026)

| Model | Type | Context | Notes |
|-------|------|---------|-------|
| Nova Pro | Language | — | Flagship, best quality |
| Nova Lite | Language | — | Fast, cost-optimized |
| Nova Micro | Language | — | Lowest latency |
| Nova Canvas | Image | — | Image generation |
| Nova Reel | Video | — | Video generation |

## Strengths
- **AWS integration**: Tight Bedrock integration
- **Enterprise**: Data isolation, VPC deployment
- **Multimodal**: Image and video generation alongside language
- **Pricing**: Competitive with other cloud providers

## Positioning
Cloud-first strategy. Competes on AWS ecosystem lock-in, enterprise features, and competitive pricing rather than benchmark leadership.
