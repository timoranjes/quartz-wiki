# xAI (Grok)

## Overview
- **Founded:** March 2023 by Elon Musk
- **Mission:** "Understand the true nature of the universe"
- **Infrastructure:** Colossus supercomputer (200K+ Nvidia H100); building Colossus 2
- **Integration:** X (Twitter), Grok.com
- **Growth:** Zero to competitive frontier LLM in ~2 years

- Grok Imagine Image: $0.02/image

## Benchmarks
- Grok 4.3 AA Intelligence Index: **53.9**
- Grok 4: 42.0 (rank #54/150)
- Behind Opus 4.8 (61.4) and GPT-5.5 (60.2)

## API & Availability
- OpenAI-compatible endpoint (api.x.ai/v1/chat/completions)
- $175/month free credits (data-sharing program)
- Consumer: Grok.com, X app integration
- Subscriptions: SuperGrok Lite ($10/mo), SuperGrok ($30/mo), SuperGrok Heavy ($300/mo)
- Cloud: Amazon Bedrock, Google Vertex AI, OpenRouter

## Strengths
- Real-time X/Twitter data access (unique)
- Configurable reasoning effort per request
- Aggressive pricing (Grok 4.1 Fast at $0.20/$0.50)
- Full-stack media (text, image, video, voice APIs)
- Consumer-first ecosystem (X platform reach)

## Weaknesses
- Fully proprietary/closed-source
- No self-hosting, fine-tuning, or model inspection
- Intelligence Index 42-54 (below top-tier)
- Knowledge cutoff: November 2024 (requires search tools)
- Founder-level exodus reported during Grok 5 development
