# OpenRouter

## Overview
OpenRouter is an **API aggregator** — provides a single API endpoint to access models from 50+ providers. Not a model creator.

## Key Offerings
- **50+ providers**: OpenAI, Anthropic, Google, Meta, xAI, Mistral, Qwen, DeepSeek, and many more
- **Unified API**: Single endpoint, single billing
- **Routing**: Automatic model selection based on price/performance
- **Free tier**: Many free models available

## Strengths
- **Coverage**: Widest model coverage of any single API
- **Price comparison**: Built-in price comparison
- **Simplicity**: One API key for everything
- **Free models**: Many free tiers aggregated

## Pricing
Varies by provider — OpenRouter adds no markup. You pay the provider's price.

## Positioning
Infrastructure layer, not a model company. Competes with Together AI, Groq, Anyscale, Replicate.
