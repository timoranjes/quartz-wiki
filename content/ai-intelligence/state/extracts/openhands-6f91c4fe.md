# OpenHands

AI agent platform for software development that executes real engineering work — not just code suggestions. Runs autonomous agents that plan, write, and apply changes across codebases, designed for enterprise software development at scale.

## Overview

- **Developer**: OpenHands (open-source community)
- **Backend Model**: Multiple LLM backends supported
- **Interface**: Web platform + CLI
- **Website**: [openhands.dev](https://www.openhands.dev/)
- **GitHub**: [OpenHands/OpenHands](https://github.com/OpenHands/OpenHands)
- **Open Source**: Yes
- **Focus**: Enterprise AI-driven development, autonomous agents

## Key Capabilities

- **Autonomous Planning**: Agents plan, write, and apply changes across entire codebases
- **Real Engineering Work**: Goes beyond code suggestion to execute actual development tasks
- **Enterprise Scale**: Designed for team-level adoption in enterprise environments
- **Open Source Foundation**: Community-driven development with transparent codebase

## History

- Originally known as OpenHands (forked from SWE-agent research)
- Evolved from academic SWE-agent project into a full agent platform
- Positioned as an open-source alternative to proprietary coding agents like Codex and Claude Code
