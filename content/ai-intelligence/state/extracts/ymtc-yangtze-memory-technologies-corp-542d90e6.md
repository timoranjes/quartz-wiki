# YMTC (Yangtze Memory Technologies Corp)

**Type:** entity
**Tags:** #semiconductor #memory #nand #china #ymtc

## Overview
YMTC is China's leading NAND flash memory manufacturer, headquartered in Wuhan. It is a key player in China's memory chip self-sufficiency efforts.

## Key Facts
- **Founded:** 2016
- **Headquarters:** Wuhan, China
- **Technology:** Xtacking architecture for 3D NAND flash
- **Achievements:** Reached 232-layer NAND, competitive with Samsung/Micron/SK Hynix
- **US Sanctions:** Added to Entity List in December 2022, restricting equipment access

## Supply Chain Impact
- Critical for China's memory chip independence
- Xtacking technology is a differentiating architecture
- Sanctions limit access to advanced deposition and etch equipment
- Expanding mature node capacity for consumer electronics
