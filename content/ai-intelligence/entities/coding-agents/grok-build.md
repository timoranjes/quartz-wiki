# Grok Build

xAI's terminal-native coding agent, launched May 2026. Features local-first execution with aggressive pricing and 8× parallel subagent support through Arena Mode.

## Overview

- **Developer**: xAI
- **Backend Model**: Grok 4.x series
- **Interface**: Terminal CLI
- **Pricing**: Included in SuperGrok and X Premium Plus subscriptions
- **Launch**: May 2026

## Key Capabilities

- **Local-first execution**: Runs on local machine, no per-token billing
- **Parallel subagents**: Up to 8× parallel subagent execution
- **Arena Mode**: Concurrent task execution (not yet generally available at launch)
- **Terminal-native**: Fits existing terminal workflows, similar to Claude Code
- **Aggressive pricing**: Included in existing xAI subscription tiers

## Workflow

1. Terminal-based task input
2. Local-first codebase reading and planning
3. Parallel subagent dispatch for independent tasks
4. Local execution and test running
5. Results reported back to user

## Competitive Positioning

- Entered the agentic coding market as the fifth major player (after Claude Code, Cursor, Codex, Antigravity)
- Aggressive pricing included in SuperGrok/X Premium Plus — no per-token billing yet
- Local-first execution appeals to privacy-conscious and cost-sensitive developers
- 8× parallel subagents is a differentiator for batch-style workloads
- Retention and enterprise adoption unproven at launch
- Limited compliance documentation compared to established players

## Pricing Model

- Included in **SuperGrok** subscription
- Included in **X Premium Plus** subscription
- No per-token billing (as of launch) — cost amortized across subscription
