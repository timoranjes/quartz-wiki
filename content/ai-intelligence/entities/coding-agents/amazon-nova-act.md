# Amazon Nova Act

AWS service for building and managing fleets of AI agents to automate production UI workflows.

## Overview

- **Developer**: Amazon Web Services (AWS)
- **Interface**: AWS service + IDE extension
- **Pricing**: AWS service pricing (TBD)
- **Launch**: Research preview → GA December 2, 2025

## Key Capabilities

- **Agent Fleet Management**: Build and manage fleets of agents for production UI workflows
- **High Reliability**: Designed for production-grade reliability with fast time-to-value
- **Ease of Implementation at Scale**: Streamlined agent building process
- **IDE Extension**: Dedicated IDE extension to streamline the agent building process
- **Production UI Workflows**: Specialized in automating UI-based production workflows

## History

- **Research Preview**: Initially launched as a research preview
- **IDE Extension**: Later introduced an IDE extension to streamline the agent building process
- **General Availability (Dec 2, 2025)**: Nova Act became generally available as a service on AWS for building and managing highly reliable AI agents at scale

## Competitive Positioning

- Positioned as an enterprise-grade agent orchestration service on AWS
- Focuses on production reliability and scale rather than developer experience
- Complements existing AWS AI services (Bedrock, Q)
- Competes with multi-agent frameworks (LangGraph, CrewAI) in the enterprise space
- Unique focus on UI workflow automation distinguishes from code-centric agents
