# Google Antigravity

Google's agentic coding platform, evolved from Gemini CLI. At Google I/O 2026 (May 19), announced as a full agent development and management platform with multi-agent orchestration, CLI, SDK, and standalone desktop app.

## Overview

- **Developer**: Google
- **Previous Name**: Gemini CLI (transitioned May 12, 2026; cutoff for free Gemini Code Assist June 18, 2026)
- **Backend Model**: Gemini 3.5 Flash (default), Gemini 3.1 Pro, Claude, GPT-OSS
- **Interface**: CLI (Go rewrite), Desktop app (Antigravity 2.0), IDE plugin, SDK, API
- **Pricing**: Free (capped), AI Pro ($19.99/mo), AI Ultra ($99.99–$200/mo)
- **Open Source**: Core open source (google-gemini-cli → antigravity-cli)

## Key Capabilities

- Autonomous code editing and project scaffolding
- Multi-agent suite with dynamic subagents
- Built-in browser for web-based workflows
- Google Cloud and Vertex AI integration
- MCP tool support
- SDK for building custom agent workflows
- Gemini 3.5 Flash: 4× faster output than peers, <50% cost of comparable frontier models

## Recent Updates (May–June 2026)

- **Google I/O 2026 (May 19, 2026)**: Major announcements — "agentic Gemini era"
  - **Gemini 3.5 Flash**: GA across all products and APIs — Terminal-Bench 76.2%, GDPval-AA 1656 Elo, MCP Atlas 83.6%
  - **Gemini Omni Flash**: "Create anything from anything" — first in Omni family, generates any output modality from any input
  - **Gemini 3.5 Pro**: Internal use; public rollout expected June–July 2026
  - **Antigravity 2.0**: Standalone desktop app for agent management, multi-surface platform (IDE → CLI → SDK → API → Cloud)
- **Gemini CLI → Antigravity CLI**: Transition announced May 12, 2026; free tier cutoff June 18, 2026
- **AI Mode**: >1B monthly users (queries doubling each quarter)
- **Google CapEx**: $180B–$190B expected for full-year 2026
- **8.5M+ developers** building with Google models monthly; 19B tokens/minute via APIs

## Notable Features

- **Multi-model choice**: Gemini, Claude, GPT-OSS
- **Multi-agent orchestration**: Dynamic subagents, built-in browser
- **Deep Google ecosystem**: Android, Google Cloud, Vertex AI integration
- **Speed advantage**: Gemini 3.5 Flash at 289 tokens/sec (4× faster than peers)
- **Cost efficiency**: <50% cost of comparable frontier models

## Competitive Positioning

- Multi-surface platform strategy (IDE, CLI, SDK, API, Cloud) most comprehensive
- Gemini 3.5 Flash is strongest value proposition in frontier tier
- UX disruption risk (IDE removal, free tier changes) has caused user concern
- Direct competitor to Claude Code (agent depth), Cursor (IDE), Codex (ecosystem)
- Growing adoption through Google Cloud customers (375+ processed >1T tokens/year)
