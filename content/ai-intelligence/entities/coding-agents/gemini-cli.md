# Google Gemini CLI

Google's CLI coding agent, built on Gemini models with deep integration into Google Cloud and Vertex AI.

## Overview

- **Developer**: Google
- **Backend Model**: Gemini 2.5 Pro, Gemini 2.0 Flash
- **Interface**: CLI (`gemini`)
- **Pricing**: Gemini API pricing + Vertex AI consumption
- **Open Source**: Open source (google-gemini-cli)

## Key Capabilities

- Autonomous code editing and project scaffolding
- 1M+ token context window (Gemini 2.5 Pro)
- Google Cloud and Vertex AI integration
- Built-in web search and code execution
- MCP tool support

## Notable Features

- **Massive context window**: Industry-leading 1M+ tokens for huge codebases
- **Gemini 2.5 Pro reasoning**: Strong analytical capabilities
- **Google ecosystem**: Tight integration with Google Cloud services
- **Free tier**: Generous free API quota for development

## Competitive Positioning

- Context window advantage over competitors
- Strong in data science and ML workflows
- Less mature agent ecosystem than Codex or Claude Code
- Growing adoption through Google Cloud customers
