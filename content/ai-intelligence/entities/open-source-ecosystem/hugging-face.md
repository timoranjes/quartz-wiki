# Hugging Face

## Overview

Hugging Face is the dominant platform for open-weight model distribution, community benchmarks, and ML collaboration. Often called the "GitHub of ML."

## Key Services

| Service | Description |
|---------|-------------|
| Model Hub | 1M+ models across all modalities |
| Datasets | 200K+ datasets for training/evaluation |
| Spaces | Demo hosting for ML applications |
| Leaderboards | Open LLM Leaderboard, task-specific rankings |
| Inference API | Serverless model inference |
| Transformers | Open-source library for model usage |

## Open LLM Leaderboard

The Open LLM Leaderboard is the primary community-driven benchmark for open-weight models. Key metrics include:

- **ARC** — Reasoning and common sense
- **HellaSwag** — Commonsense NLI
- **MMLU** — Multi-task language understanding
- **TruthfulQA** — Truthfulness and factuality
- **Winogrande** — Pronoun disambiguation

## Market Position

- **Strengths**: Network effects (most models published here), free tier access, active community, comprehensive tooling
- **Weaknesses**: Quality control challenges (anyone can publish), benchmark manipulation risk
- **vs. Commercial**: Open-weight models on HF increasingly competitive with closed models

## Significance for Intelligence Wiki

Hugging Face is the primary source for tracking:
1. New open-weight model releases
2. Community benchmark results
3. Model commoditization signals
4. Emerging model architectures
