## Capabilities
- **Agentic Engineering**: GLM-5 achieves SOTA on SWE-bench Verified and Terminal Bench 2.0, matching Claude Opus 4.5 on core agentic benchmarks
- **Visual Language**: GLM-4.6V is a leading 100B-class open-source VLM with SOTA visual understanding accuracy
- **Screen-Only Agent Control**: AutoClaw enables autonomous PC control using only screenshots (no HTML/API parsing needed)
- **AutoGLM**: Autonomous agent model supporting planning, reasoning, execution, and self-improvement (>50-step long chains)
- **GLM-PC**: Visual-based PC control with human-like desktop interaction (closed beta)
- **Model-as-a-Service**: Enterprise-grade APIs with model fine-tuning (<10 min setup) and AI web search tools
- **CogAgent-9B**: Open-source agent model based on GLM-4V-9B, specialized for screen-based agent tasks

## Key Facts
1. Zhipu AI (Z.ai) is publicly traded on HKEX (02513) and released its 2025 annual results on March 31, 2026.
2. GLM-5 is positioned as the base model for Agentic Engineering, matching Claude Opus 4.5 on core agentic benchmarks while being open-source.
3. GLM-4.7-Flash is a 30B-A3B MoE model presented as the strongest in the 30B class, designed for lightweight local coding and agent workloads.
4. AutoClaw is China's first one-click installable local OpenClaw client with 50+ built-in skills and integrated AutoGLM browser operation capability.
5. Zhipu AI chaired the Zhongguancun Autonomous Large Model Industry Alliance (32 members, August 2025).
6. The company maintains strong open-source commitment with the GLM series (ChatGLM-6B through GLM-5) widely adopted in research and industry.
