# Aider

## Company Facts
- **Developer**: Paul Gauthier (open-source project)
- **License**: Apache 2.0
- **Type**: Open-source CLI AI pair programming tool
- **GitHub**: https://github.com/Aider-AI/aider (44K+ stars as of 2026)
- **Installs**: 6.8M+ via PyPI (aider-chat package)
- **Weekly Token Volume**: 15B+ tokens/week

## Model Lineup
Aider is model-agnostic and works with 75+ LLM providers:

| Provider | Models Supported |
|----------|-----------------|
| Anthropic | Claude 3.7 Sonnet, Claude Opus, Claude Sonnet |
| OpenAI | GPT-4o, o1, o3-mini |
| DeepSeek | DeepSeek R1, DeepSeek Chat V3 |
| Local | Any OpenAI-compatible local model via Ollama |
| Others | 75+ total providers supported |

## Capabilities
- **Git-First Philosophy**: Every AI edit automatically becomes a git commit with a descriptive message; sessions can run on their own branches
- **Codebase Mapping**: Creates a repo map of the entire codebase (files, functions, relationships) for coordination across large projects
- **100+ Languages**: Works with Python, JavaScript, Rust, Ruby, Go, C++, PHP, HTML, CSS, and dozens more
- **Git Integration**: Automatic commits, branching, rollback; uses familiar git tools to diff, manage, and undo AI changes
- **IDE Integration**: Can be used from within IDEs by adding comments to code
- **Images & Web Pages**: Add images and web pages to chat for visual context, screenshots, reference docs
- **Voice-to-Code**: Speak requests for features, test cases, or bug fixes
- **Auto Lint & Test**: Automatically lint and test code after every change; can fix problems detected by linters and test suites
- **Copy/Paste Mode**: Works with LLM web chat interfaces when API access is unavailable
- **Singularity**: 88% of new code in recent releases was written by Aider itself

## Key Facts
1. Aider is a Python-based open-source CLI tool that pioneered the git-first approach to AI coding — every edit is reviewable, revertable, and traceable via standard git tools.
2. With 44K+ GitHub stars and 6.8M+ installs, it is one of the most widely adopted open-source AI coding CLIs.
3. Aider's repo map feature provides codebase-wide coordination, making it particularly effective for large monorepos.
4. Supports 75+ LLM providers including local models via Ollama, making it highly flexible for model selection.
5. The tool's "Singularity" metric shows 88% of new code in its own releases is written by Aider, demonstrating self-improvement.
6. Aider is best suited for git-heavy workflows, large-scale refactoring, and developers who value traceability and code review.
