# Cursor AI Coding Agent

## Overview

Cursor is an AI-powered coding environment and agent platform designed to dramatically increase developer productivity. It functions as both an IDE (Integrated Development Environment) and a multi-agent system, enabling autonomous code generation, testing, and deployment. Cursor supports any major model provider and offers features like Composer 2.5 for agentic workflows, cloud agents that run tasks in parallel, and deep codebase understanding with semantic search and indexing.

The platform has gained significant adoption across major tech companies. Y Combinator reported adoption jumping from single digits to over 80% among their portfolio companies. NVIDIA CEO Jensen Huang stated every one of their 40,000 engineers are now assisted by AI. Cursor provides an autonomy spectrum ranging from Tab completions to Cmd+K inline edits to full agentic mode, giving developers granular control over AI involvement.

## Key Details

### Features
- **Autonomous Agents**: Run tasks end-to-end (plan, build, test, deploy) in parallel on dedicated compute resources
- **Composer 2.5**: Agentic interface for planning and building complex features with `/` commands, `@` file references, and `!` shell commands
- **Tab Model**: Specialized autocomplete model optimized for context-aware completions and bracket handling
- **Multi-Modal Integration**: Available as desktop IDE, CLI terminal (`curl https://cursor.com/install -fsS | bash`), Slack (`@cursor`), and GitHub (PR reviews)
- **Cloud Agents**: Agents run on Cursor's infrastructure for background tasks
- **Codebase Understanding**: Semantic search and indexing across entire codebases
- **Mission Control Interface**: Grid view of open windows as live scaled previews
- **MCP Support**: Connects to external tools and data sources via Model Context Protocol
- **Bugbot**: Agentic code review tool
- **Privacy Mode**: Guarantees code data is never stored or used for training

### Pricing (Monthly)
- **Hobby**: Free — limited Agent requests, limited Tab completions, no credit card required
- **Individual**:
  - **Pro**: $20/mo — extended limits, frontier model access, MCPs, skills, hooks, cloud agents
  - **Pro+**: Higher usage tier for daily agent users
  - **Ultra**: Highest tier for agent power users
- **Teams**: $40/user/mo — centralized billing, team marketplace, Bugbot code reviews, shared team context, usage analytics, SAML/OIDC SSO, team-wide privacy mode
- **Enterprise**: Custom pricing — pooled usage, invoice/PO billing, SCIM seat management, repository/model/MCP access controls, audit logs, AI code tracking API

### Model Support
- Supports any major model provider
- Frontier model access on paid tiers
- Usage-based billing beyond included amounts
