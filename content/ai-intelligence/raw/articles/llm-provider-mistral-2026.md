## Capabilities
- **Reasoning**: Mistral Small 4 unifies instruct, reasoning, and coding in a single model
- **Coding**: Devstral 2 for software engineering tasks; Codestral for code completion
- **Vision**: Multimodal input support across Frontier models (Medium 3.5, Large 3, Ministral 3)
- **Audio**: Voxtral stack — TTS (zero-shot voice cloning), transcription (batch & realtime), audio input
- **Tool Use**: Function calling, structured output across models
- **Agentic**: Medium 3.5 optimized for agentic use cases
- **OCR**: OCR 3 powers Document AI stack (Premier license)
- **Moderation**: Mistral Moderation 2 with 128K context and jailbreak detection

## Key Facts
1. Mistral AI was founded in June 2023 by Arthur Mensch (CEO), Guillaume Lample (CSO), and Timothée Lacroix.
2. Based in Paris, France — Europe's leading frontier AI company.
3. Raised €1.7B (~$1.8B) in Series C at €11.7B post-money valuation, one of the largest European AI funding rounds.
4. Mistral offers both open-weight models (most models) and Premier-licensed models (Codestral, OCR, Embed).
5. Max context window of 262K tokens on Ministral 3 and Devstral 2 models.
6. Mistral Large 3 costs $2/1M input and $6/1M output at the API (per mistral.ai/pricing).
