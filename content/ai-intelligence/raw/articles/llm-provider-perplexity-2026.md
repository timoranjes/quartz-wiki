# Perplexity

## Company Facts
- **Founded**: 2022
- **HQ**: San Francisco, California
- **CEO**: Aravind Srinivas
- **Core Product**: AI-powered search engine and API platform

## Model Lineup
Perplexity's Sonar API family provides web-grounded LLM responses:

| Model | Type | Description |
|-------|------|-------------|
| Sonar | Search | Lightweight, cost-effective search model with grounding. Best for quick factual queries and topic summaries. |
| Sonar Pro | Search | Advanced search with grounding, supporting complex queries and follow-ups. |
| Sonar Reasoning Pro | Reasoning | Precise reasoning with Chain of Thought (CoT). Excellent for multi-step analysis and logical problem-solving. |
| Sonar Deep Research | Research | Expert-level research model conducting exhaustive web searches and generating comprehensive reports. |
| pplx-embed | Embeddings | State-of-the-art embedding models optimized for web-scale retrieval. |

### Agent API
- **Agent API** (launched March 2026): Managed runtime for agentic workflows across frontier models with built-in web search, URL fetching, and reasoning controls.

## Capabilities
- **Web-Grounded Responses**: Real-time web search integration with citations in all Sonar models
- **Search API**: Low-latency hybrid search combining semantic methods, LLM ranking, and human feedback
- **Embeddings API**: pplx-embed for RAG, semantic search, and document clustering
- **Citations**: All responses include source citations
- **OpenAI-Compatible**: Sonar API works with OpenAI-compatible client libraries
- **Streaming**: Supports streaming responses
- **Structured Output**: JSON mode for structured responses

## Key Facts
1. Perplexity's Sonar API provides web-grounded LLM responses with built-in citations, making it unique among LLM providers.
2. The Agent API (March 2026) offers a managed runtime for agentic workflows with model-agnostic support.
3. pplx-embed delivers state-of-the-art embedding performance for web-scale retrieval, outperforming open-source and commercial alternatives.
4. Enterprise customers include Zoom (AI Companion 2.0), SAP (Joule), and Doximity (clinical decision support).
5. Perplexity APIs power AI browsing on Samsung devices, reaching the world's largest Android device maker.
