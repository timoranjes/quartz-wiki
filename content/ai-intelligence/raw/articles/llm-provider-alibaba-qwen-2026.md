# Alibaba (Qwen)

## Company Facts
- Founded: 2023 (Qwen team; Alibaba Group founded 1999)
- HQ: Hangzhou, China
- Leadership: Jingren leads Tongyi Large Model Business Unit (Tongyi Lab)
- Parent: Alibaba Group (Alibaba Cloud provides Qwen models)

## Capabilities
- **Reasoning**: Qwen3.7 described as "The Agent Frontier" — agentic reasoning focus
- **Vision**: Multimodal models with image and video understanding
- **Audio**: Qwen3.6-Plus supports audio/video modalities
- **Tool Use**: Full tool calling and agent frameworks
- **Coding**: Qwen3-Coder series (480B A35B) specialized for code
- **Document Processing**: PDF, CSV, Office suite document processing via Qwen Studio
- **Image Generation**: Qwen Image 2.0 and 2.0 Pro available

## Key Facts
1. Qwen is developed by Alibaba's Tongyi Lab (formerly Tongyi Large Model Business Unit), led by Jingren.
2. Alibaba Cloud provides Qwen models as open-source to the community via Alibaba Cloud Model Studio.
3. Qwen3.7 (2026) focuses on agentic capabilities with the tagline "The Agent Frontier."
4. Qwen Flash offers tiered pricing with a free tier for low-volume usage.
5. The Qwen family includes LLMs, vision models, audio models, coding models, and image generation models.
