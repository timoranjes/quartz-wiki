# GitHub Copilot

## Company Facts
- **Developer**: GitHub (Microsoft)
- **Launch**: 2021 (initial), evolved to full agent platform by 2026
- **Type**: AI pair programmer with agent capabilities
- **User Impact**: 75% higher job satisfaction, up to 55% more productivity reported by users

## Capabilities
- **Code Completion**: Inline suggestions based on current code context (unlimited and credit-free)
- **Agent Mode**: Assign tasks to agents (Copilot, Claude, Codex) that plan, explore, and execute in background
- **Chat in IDEs**: Explanations, refactoring, debugging across VS Code, JetBrains, Visual Studio, Xcode, Neovim, Eclipse, Zed
- **Copilot CLI**: Natural language terminal workflows leveraging GitHub context (repos, issues, PRs)
- **Copilot Spaces**: Turn Copilot into project expert using docs and repos as context
- **Copilot Code Review**: AI-assisted PR reviews with deep analysis (available to all PRs on GitHub.com)
- **Copilot Autofix**: Integrated with GitHub Advanced Security; suggests fixes for vulnerabilities
- **Model Context Protocol (MCP)**: Third-party tool integrations (paid tiers)
- **Third-Party Agents**: Support for custom and third-party agents (paid tiers)
- **Codebase Indexing**: Organization-wide codebase understanding (Enterprise tier)

## Key Facts
1. GitHub Copilot evolved from autocomplete suggestions to a full agent platform supporting third-party agents (Claude, Codex) by 2026.
2. Code completions and next-edit suggestions are unlimited and do not consume AI credits.
3. GitHub Copilot moved from request-based to usage-based billing on June 1, 2026, with AI Credits (1 credit = $0.01 USD).
4. Copilot Code Review begins consuming GitHub Actions minutes on June 1, 2026.
5. IP Indemnity: GitHub and Microsoft provide copyright protection for unmodified suggestions when filtering is enabled.
6. Business/Enterprise data is NOT used for model training; individual tier data may be used unless opted out.
7. 75% higher job satisfaction and up to 55% more productivity reported by Copilot users.
